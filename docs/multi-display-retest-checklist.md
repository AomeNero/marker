# Marker 双显示器问题复测清单

你好！感谢帮忙测试 Marker 的双显示器功能。这个版本修复了多屏标注的一批问题，麻烦按下面的步骤走一遍，把结果反馈给我。

## 第一步：采集环境信息（只需一次）

1. 在桌面右键 → **显示设置**，截一张完整的设置页面图（能看到两块显示器的示意图、各自的分辨率和缩放比例）
2. 告诉我哪块是主显示器（设置里编号为 1 的那块）
3. Marker 版本：设置 → 关于 里查看（应该是 1.0.3 或更新）

## 第二步：核心场景复测（最重要）

> 这一步专门验证"启动后马上使用"的场景，**动作要快**。

1. 完全退出 Marker（托盘图标右键退出）
2. 重新启动 Marker
3. **3 秒内**按下全局快捷键进入标注模式
4. 分别在**两块屏幕**上各画一笔，记录：
   - [ ] 第一屏能画吗？
   - [ ] 第二屏能画吗？如果第二屏鼠标点了没反应（像被什么东西挡住），也请记下来
5. 按键盘 `W` 进入白板模式，记录：
   - [ ] 第一屏变白板了吗？
   - [ ] 第二屏也变白板了吗？

> 如果第 3 步来不及（手速不够快），可以多试几次：退出 → 重开 → 3 秒内进标注。出现一次问题就算复现成功。

## 第三步：正常场景复测

1. 启动 Marker 后**等 10 秒以上**再进入标注模式
2. 重复第二步的画笔和白板检查
3. 按 `Esc` 退出，再按快捷键重新进入，再检查一遍两屏

## 第四步：如果第二屏仍有问题，帮我判断是哪种

在标注模式下看第二块屏幕：

| 现象 | 说明 |
|------|------|
| A. 第二屏完全正常，鼠标能点桌面图标，但也**画不了**（鼠标像穿过屏幕） | 覆盖层没出现 |
| B. 第二屏鼠标**点不了任何东西**（像被一块透明玻璃挡住），但也看不到画笔笔迹 | 覆盖层在但没激活（这正是本次修复的目标场景） |
| C. 第二屏能画，但**白板**只有一屏变白 | 白板同步问题 |

请告诉我对应哪种（可以多种并存）。

## 第五步（可选）：导出诊断日志

设置 → 关于（或帮助）里如有"导出诊断信息"，请导出发给我，能帮我精确定位。

## 反馈方式

把以下信息发给我：
1. 显示设置截图
2. 第二步、第三步两个表格的勾选结果
3. 第四步的选项（A / B / C）
4. 诊断日志（如有）

谢谢！
